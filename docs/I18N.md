# Internationalization

## Routes

- Persian (`fa`) is the default at unprefixed routes; English (`en`) uses `/en/`.
- Never redirect from browser language. The language switcher links to the equivalent route.
- Build asset URLs with `withBasePath`; build page URLs with `getLocalePath`.

## Content ownership

- `src/content-data/resume.json` remains the factual source in every language through the typed `src/data/resume.ts` adapter.
- `src/i18n/resume-fa.ts` translates canonical records by stable ID; it must not add facts.
- `src/i18n/{fa,en}.ts` owns UI copy and must satisfy the shared dictionary type. Bilingual profile presentation is in `src/content-data/profile.json`.
- Project Markdown is canonical. `projects-fa.json` is localized presentation keyed by the same collection ID.
- Posts declare a locale and optional `translationKey`; do not imply a translation exists.

## UI rules

- Pass `locale` through layouts and sections; do not inspect browser state.
- Preserve document-level `lang`/`dir`, logical CSS properties, isolated LTR technical terms, localized metadata, and `hreflang` pairs.
- Keep language controls native links and routes fully static without framework hydration. The shared theme preference enhancement is locale-neutral and persists across locale links.
